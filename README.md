# Умный офис

## Информация о проекте
**Дисциплина:** МДК 03.01. Разработка приложений взаимодействия с интеллектуальными интегрированными системами
**Специальность:** 09.02.08 Интеллектуальные интегрированные системы
**Номер в журнале:** 16

## Цель проекта
Разработать виртуальный прототип системы "Умный офис", обеспечивающий мониторинг температуры и влажности, автоматическое управление охлаждением серверной и возможность ручного управления вентилятором.
