# Умный офис

Учебный проект по созданию виртуальной системы мониторинга и автоматизации офисного помещения.

**Дисциплина:** МДК 03.01. Разработка приложений взаимодействия с интеллектуальными интегрированными системами  
**Специальность:** 09.02.08 Интеллектуальные интегрированные системы  
**Группа:** 54-15  
**Номер в журнале:** 16

## О проекте

Цель проекта — разработать прототип умного офиса, который позволяет отслеживать температуру и влажность, автоматически управлять вентиляцией серверной и сохранять историю показаний.

Система построена в GNS3 с использованием виртуальных машин РЕД ОС 8 и Windows Server 2019.

## Состав системы

| Устройство | Назначение |
|---|---|
| WIN | Рабочее место администратора, Windows Server 2019 |
| IOT | Эмуляция датчиков и вентилятора в Node-RED |
| CTRL | Приём показаний и предоставление метрик |
| DB | Хранение истории показаний в SQLite |
| MON | Мониторинг через Prometheus и Grafana |
| RTR | Маршрутизация между VLAN и выход в интернет |
| SW | Подключение устройств и разделение сети на VLAN |

## Принцип работы

На IOT в Node-RED созданы виртуальные устройства:

- **TEMP-01** — датчик температуры серверной.
- **HUM-01** — датчик влажности рабочей зоны.
- **FAN-01** — имитация вентилятора.

Датчики автоматически отправляют показания каждые 5 секунд.

Состояние вентилятора определяется температурой через условие в Node-RED. При выполнении условия вентилятор включается (`ON`), иначе выключается (`OFF`).

Данные поступают на CTRL для мониторинга и на DB для сохранения в SQLite.

Prometheus собирает метрики с CTRL, а Grafana отображает их на панели мониторинга. Если датчик перестаёт отправлять показания более 20 секунд, Grafana формирует оповещение и отправляет письмо администратору.

## Используемые технологии

- **GNS3** — моделирование компьютерной сети.
- **РЕД ОС 8** — операционная система серверов.
- **Docker Compose** — запуск контейнерных приложений.
- **Node-RED** — моделирование датчиков и управления вентилятором.
- **SQLite** — хранение истории показаний.
- **Prometheus** — сбор метрик.
- **Grafana** — визуализация и оповещения.
- **GitHub** — хранение исходников, конфигураций и документации.

## Запуск и проверка

После запуска виртуальных машин необходимо убедиться, что работают:

1. Контейнер Node-RED на IOT.
2. Приёмник на CTRL.
3. Сервис SQLite на DB.
4. Системные службы Prometheus и Grafana на MON.

Контейнеры настроены на автоматический перезапуск, а службы мониторинга добавлены в автозагрузку.

Для проверки откройте Grafana, убедитесь в поступлении показаний и проверьте статус `UP` у цели `office-controller` в Prometheus.
